How it works

The calculator, not the model, is the knowledge base

Frontier LLMs write confident-but-wrong numbers. Labwright changes the contract: the model only proposes raw inputs (geometry, flows, seeding), and everything derived — shear stress, volumes, cell counts, dosing — is computed by deterministic physics calculators and re-proved by a verifier before a design is ever submitted.

What you get

Verified numbers, reverse-verified protocols

  • No fabricated numbers. Every derived value is recomputed from its own raw inputs — an internally inconsistent design is rejected, not shipped.
  • Reverse-verify published protocols. Paste a paper's geometry and flow; the verifier recomputes its shear/volumes and flags numbers that don't follow from the paper's own inputs.
  • Domain-aware sanity. Physiological bands and unit aliases (µm↔mm, µL↔mL, dyn/cm²↔Pa) catch order-of-magnitude and unit-misread errors.
  • Cross-domain. Microfluidics (OOC), plate culture, and 3D spheroid/organoid working volumes — one verified-design path.

The seven post-v1 domains (barrier, oxygen, pumpless, breathing, pulsatile, scaling, gradient) were benchmarked end-to-end with the Labwright system on the 14 new-domain goals (no bare-memory baseline was run on this set). Flash submits 13/14, pro 11/14; among submitted designs hallucination is 0.000 on both. The honest boundary: the gradient-fgf8-pattern goal ends in silence on both models, and the fine-tuned extractor — trained across all eleven domains on ~49.8k synthetic goals — answers 4/14 here (v4 scored 0/14): the v5 retrain adds hand-written-register variants for these domains, closing part of the phrasing gap; the remaining 10/14 still end in silence rather than fabrication (hallucination 0.446).

Memory-only systems (bare, soft-gate, self-verify) rarely produce a usable design. Labwright's derived numbers are architecturally consistent — the honest headline is the blind-set drop: the gate stops fabricated numbers, but it cannot supply domain knowledge the model does not have. That boundary is the point. The gap is stable across seeds (95 % Wilson intervals never overlap the memory systems), and an iterating fix-and-resubmit agent (labwright_iter) repairs all 41 verifier-fired entries yet is a wash on usable rate — iteration is a correctness loop, not a domain-knowledge loop.

The same verifier ran over the literature: an audit of 21,094 real SciRecipe protocol summaries, with each quoted title resolved to a verified Crossref DOI. The full audit (verdicts, numbers, DOI provenance) is released as an open dataset: qgeng1465/scirecipe-audit.

Try it

Run it yourself

Clone the repo and verify a published protocol's numbers in seconds — no API key needed for reverse verification (pure deterministic physics):

  • pip install -e . then labwright verify-protocol "…" for the CLI, or labwright ui for the interactive app.
  • The interactive design tab calls an OpenAI-compatible API (a Space secret in the Gradio deployment; a DEEPSEEK_API_KEY locally).
  • Full benchmark protocol, per-entry records, and honest caveats: the repo's eval/ directory.
